===================================================
Технический проект транслятора выражений Py-to-C
===================================================

1. Общее описание проекта
=========================

Проект переводит простые программы на Python в эквивалентный код на языке Си. 

Поддерживаемые возможности:
- Целые числа (``int``) и числа с плавающей точкой (``float``).
- Логические литералы (``True``, ``False``).
- Переменные и операция присваивания (``=``).
- Арифметика: сложение (``+``), вычитание (``-``), умножение (``*``), деление (``/``) и степень (``**``).
- Приоритет операций и круглые скобки.

Для работы с динамическими типами в Си используется библиотека ``object.h`` / ``object.c``, где все значения хранятся в универсальной структуре ``object_t`` и передаются через указатели ``object_t*``.


2. Структура проекта
====================

- ``input.py`` — исходный файл с кодом на Python.
- ``lexer.py`` — лексический анализ: чтение символов и разбиение на токены.
- ``parser.py`` — синтаксический анализ: построение AST-дерева и генерация кода Си.
- ``object.h`` — заголовочный файл библиотеки Си: описание структуры ``object_t`` и прототипов функций.
- ``object.c`` — реализация динамических объектов и операций на Си.
- ``output.c`` — результирующий файл на Си.
- ``docs.rst`` — документация технического проекта.


3. Модуль лексического анализа (lexer.py)
=========================================

Класс Token
-----------
Хранит тип лексемы и ее строковое значение.

- ``__init__(token_type, value=None)``: сохраняет переданный тип токена и его значение.
- ``__str__()``: возвращает читаемую строку для вывода и отладки токена.

Класс Lexer
-----------
Посимвольно читает исходный файл и собирает распознанные токены.

- ``__init__(filename)``: открывает файл на чтение в кодировке ``utf-8-sig`` (с автоматическим отсечением метки BOM) и считывает в буфер первый символ.
- ``advance()``: считывает следующий символ из файла в буфер ``self.ch``.
- ``skip_whitespace()``: пропускает пробелы, знаки табуляции, неразрывные пробелы и переводы строк.
- ``read_identifier_or_keyword()``: считывает слово целиком. Если это ``True`` или ``False`` — возвращает токен логического типа, иначе токен переменной (``Id``).
- ``read_number()``: считывает цифры. Если находит точку — формирует токен ``Float``, иначе токен ``Int``.
- ``get_token()``: определяет текущий символ и возвращает соответствующий токен (число, ключевое слово, оператор или конец файла).
- ``close()``: закрывает исходный файл.


4. Модуль синтаксического анализа и генерации кода (parser.py)
==============================================================

Узлы синтаксического дерева (AST)
---------------------------------

Каждый узел дерева хранит свои данные и имеет метод ``to_c()`` для вывода соответствующего фрагмента Си-кода.

- ``NumberNode``:
  
  - Поля: ``value`` — числовое значение.
  - ``to_c()``: возвращает вызов конструктора ``INT(...)`` или ``FLOAT(...)``.

- ``BoolNode``:
  
  - Поля: ``value`` — строка ``"True"`` или ``"False"``.
  - ``to_c()``: возвращает вызов функции ``TRUE()`` или ``FALSE()``.

- ``VariableNode``:
  
  - Поля: ``name`` — имя переменной.
  - ``to_c()``: возвращает имя переменной без изменений.

- ``BinOpNode``:
  
  - Поля: ``left`` (левый операнд), ``op`` (знак операции), ``right`` (правый операнд).
  - ``to_c()``: подставляет вызов функции Си в зависимости от знака: ``ADD``, ``SUB``, ``MUL``, ``DIV`` или ``POW_OP``.

- ``AssignNode``:
  
  - Поля: ``target`` (имя переменной слева), ``value`` (узел выражения справа).
  - ``to_c(declared_vars)``: генерирует строку присваивания. Если переменная встречается впервые — добавляет тип ``object_t*``, если повторно — просто имя.

- ``ProgramNode``:
  
  - Поля: ``statements`` — список узлов присваивания программы.
  - ``to_c()``: формирует итоговый Си-код, подключает ``stdio.h``, ``object.h`` и помещает все команды внутрь функции ``main()``.

Класс Parser
------------
Строит синтаксическое дерево выражений методом рекурсивного спуска.

- ``__init__(lexer_instance)``: принимает лексер и считывает первый токен.
- ``advance()``: запрашивает следующий токен у лексера.
- ``match(expected_type)``: проверяет, совпадает ли текущий токен с ожидаемым типом, и делает шаг вперед.
- ``parse_factor()``: разбирает базовые элементы (числа, True/False, переменные, выражения в скобках).
- ``parse_power()``: разбирает оператор возведения в степень (``**``) с правой ассоциативностью.
- ``parse_term()``: разбирает операции умножения (``*``) и деления (``/``).
- ``parse_expression()``: разбирает операции сложения (``+``) и вычитания (``-``).
- ``parse_statement()``: разбирает отдельное выражение присваивания (``переменная = выражение``).
- ``parse()``: последовательно разбирает строки программы до токена конца файла.

Класс Coordinator
-----------------
Организует общую работу транслятора.

- ``__init__(filename)``: запоминает путь к исходному файлу Python.
- ``run()``: запускает лексер и парсер, выводит дерево AST в консоль и сохраняет Си-код в файл ``output.c``.


5. Библиотека времени выполнения на Си (object.h, object.c)
===========================================================

Структура данных object_t
-------------------------
Универсальный контейнер для динамической типизации:
- ``TypeTag type`` — метка фактического типа данных (``TYPE_INT``, ``TYPE_FLOAT``, ``TYPE_BOOL``).
- ``union data`` — объединение, хранящее само значение (``int_val``, ``float_val`` или ``bool_val``).

Функции создания объектов (конструкторы)
----------------------------------------
- ``object_t* INT(long long v)``: выделяет память в куче через ``malloc`` и записывает целое число.
- ``object_t* FLOAT(double v)``: выделяет память через ``malloc`` и записывает вещественное число.
- ``object_t* TRUE(void)``: выделяет память и создает объект типа ``TYPE_BOOL`` со значением ``true``.
- ``object_t* FALSE(void)``: выделяет память и создает объект типа ``TYPE_BOOL`` со значением ``false``.

Вспомогательные функции приведения типов
----------------------------------------
- ``to_double(object_t* obj)``: считывает значение объекта и возвращает его в виде числа типа ``double``.
- ``to_int(object_t* obj)``: считывает значение объекта и возвращает его в виде числа типа ``long long``.

Операции над объектами
----------------------
- ``object_t* ADD(object_t* a, object_t* b)``: сложение. Возвращает объект ``FLOAT``, если хотя бы один аргумент дробный, иначе ``INT``.
- ``object_t* SUB(object_t* a, object_t* b)``: вычитание. Возвращает объект ``FLOAT`` или ``INT``.
- ``object_t* MUL(object_t* a, object_t* b)``: умножение. Возвращает объект ``FLOAT`` или ``INT``.
- ``object_t* DIV(object_t* a, object_t* b)``: деление. Всегда возвращает результат как ``FLOAT`` (по правилам Python 3).
- ``object_t* POW_OP(object_t* a, object_t* b)``: возведение в степень с помощью функции ``pow``.
- ``void print_object(object_t* obj)``: печатает значение объекта в консоль в соответствии с его типом.
