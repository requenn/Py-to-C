=============================================
Конвертация кода из Python в С
=============================================

Что поддерживается
==================

Программа работает с простыми строками присваивания значений переменным:

* **Операция присваивания**: базовый синтаксис вида ``имя = значение``.
* **Имена переменных (идентификаторы)**: состоят из латинских букв, цифр и знака подчеркивания ``_``. Не могут начинаться с цифры (например: ``count``, ``temp_1``, ``_val``).
* **Целые числа (тип int)**: положительные и отрицательные числа без точки (например: ``42``, ``-10``).
* **Вещественные числа (тип float / double)**: числа с десятичной точкой, как положительные, так и отрицательные (например: ``3.14``, ``-0.5``).
* **Присваивание одной переменной в другую**: когда справа от знака равно стоит имя другой переменной (например: ``result = count``).
* **Форматирование**: игнорируются любые пробелы и пустые строки вокруг знака ``=`` и между командами.

Какую часть языка Python поддерживает транслятор
================================================

Транслятор поддерживает только самое начальное, линейное подмножество языка Python — **объявление и инициализацию переменных константами или другими переменными**.

Вся остальная часть языка Python на текущем этапе **НЕ поддерживается**:

* **Арифметические операции**: нельзя использовать знаки действий между переменными и числами (например: ``a = b + 5`` или ``x = 2 * y``). Справа от знака ``=`` должно находиться только одно одиночное значение.
* **Строки и символы**: текст в кавычках (``text = "hello"``).
* **Логический тип**: значения ``True`` и ``False``.
* **Управляющие конструкции**: ветвления (``if / else``), циклы (``for``, ``while``).
* **Сложные типы данных**: списки, словари, кортежи, множества.
* **Подпрограммы**: объявление и вызов функций (``def``), классы (``class``).
